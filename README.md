# 🦈 XVC++ | Xbox Virtual Controller

**XVC++** transforms your keyboard and mouse into a high-precision Xbox 360 controller.

Born as a Rust prototype, it was rebuilt in **native C++** for maximum performance and direct hardware access via the ViGEmBus driver. Every line is optimized for low latency and smooth analog response.

---

## ⚡ Core Features
- **3 Mouse Modes:** Absolute, Spring, and Absolute Boost (dynamic speed control)
- **Progressive Triggers:** Keys behave like analog pedals with adjustable attack/release
- **Universal Axis Mapping:** Assign mouse movement to any stick
- **Real-time Config:** Color-coded UI with INI persistence
- **Thread-safe:** Built for stability

---

## 📦 Requirements

- Windows 10 / 11
- [ViGEmBus Driver](https://github.com/ViGEm/ViGEmBus/releases) (required for controller emulation)
- [Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe)
